# Ticket-Assignment-Analysis

It performs data cleaning (handling missing values, converting to string, creating RawDescription by concatenating Short description and Description).

It computes word counts, generates word clouds for Short description, RawDescription, and Description columns.

It uses libraries like pandas, numpy, matplotlib, seaborn, sklearn, wordcloud, re.
